> 目标：拿到一个**永久在线、关机不失效**的网址，微信发出好友能在手机上完成全部操作。
> 分工：⭐ 标记的步骤必须你本人点（要邮箱验证码、要授权、要设密码），其余全部我来做。

## 阶段 1：把代码放进 GitHub（约 5 分钟）

1. ⭐ 注册账号：打开 https://github.com/signup ，填邮箱、密码、用户名，收邮件验证码完成验证。
2. ⭐ 装 GitHub Desktop（比命令行省事）：https://desktop.github.com/ ，装好打开，用刚才的账号登录。
3. ⭐ 在 GitHub Desktop 里：`File → Add local repository` → 选 `D:\旅游费用查询网站` → 它会识别出这是一个 git 仓库 → 点顶部 `Publish repository`：
   - Name 填 `travel-cost-site`
   - **取消勾选** `Keep this code private`（公开仓库，Render 拉代码不需要额外授权）
   - 点 `Publish repository`
4. 完成后告诉我仓库地址（形如 https://github.com/你的名字/travel-cost-site），或直接说"推上去了"。

> 我这边的准备已经做完：仓库里已有 48+ 文件、`.gitignore` 生效（node_modules/dist/.env 不入库）、首次提交在 main 分支。

## 阶段 2：开一个免费的云数据库（约 8 分钟）

1. ⭐ 注册：打开 https://tidbcloud.com ，用 Google 或 GitHub 账号直接登录（不用另设密码）。
2. ⭐ 建集群：右上角 `Create Cluster` → 选 **Serverless**（有免费额度，别选 Dedicated 要钱）→ 区域选 `AWS / Singapore`（离国内近）→ 点 `Create`。
3. ⭐ 等 2-3 分钟状态变 `Active` → 点 `Connect` → 记下三项：
   - `Host`（形如 xxx.xxx.prod.aws.tidbcloud.com）
   - `Port`（一般是 4000）
   - `User`（形如 abcd1234.root）
4. ⭐ 点 `Generate Password` → 复制那串密码（**关掉就再也看不到**，马上保存）。
5. ⭐ 把这三项 + 密码填进这个文件：`D:\旅游费用查询网站\云端数据库连接.txt`（我已经建好模板，**别发到聊天里**）。
   填完告诉我"数据库信息填好了"。

---

## 阶段 3：让网站上线（约 5 分钟，主要是等）

1. ⭐ 注册：打开 https://render.com ，点 `Get Started` → 用 **GitHub 登录** → 允许授权。
2. ⭐ 点 `New + ` → `Blueprint` → 选阶段 1 的仓库 `travel-cost-site`（它会自动读 `render.yaml`）。
3. ⭐ 在环境变量里补三个值（从阶段 2 的文件里复制）：
   - `DB_HOST` = 你的 Host
   - `DB_USER` = 你的 User
   - `DB_PASSWORD` = 你的密码
   （`DB_PORT`/`DB_NAME`/`DB_SSL`/`JWT_SECRET` 我已经在 render.yaml 里配好，JWT_SECRET 由 Render 自动生成）
4. ⭐ 点 `Apply` / `Create`，等 3-6 分钟。
5. 把 Render 给你的网址（形如 https://travel-cost-site-xxxx.onrender.com）告诉我。

> 之后的活我全包：在云库上建表灌数据、验证 `/api/health`、手机端 + 微信里实测、把新网址给你。

## 常见坑（先记着，遇到不慌）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Render 打开很慢（约 50 秒） | 免费实例 15 分钟没人访问会休眠 | 正常现象，有人访问就醒 |
| 部署日志红字 `DB_SSL` / certificate | TiDB 证书链校验 | 我把 `DB_SSL_REJECT_UNAUTHORIZED` 设 false |
| `ECONNREFUSED` / `ETIMEDOUT` | DB_HOST 填错或集群休眠 | 回 TiDB 控制台核对 Host |
| 页面白屏但 /api/health 正常 | 前端没打包进构建 | 我查 build 日志 |
