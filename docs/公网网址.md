# 网址与上线说明

## 正式网址（永久，发微信给好友就行）

```
https://travel-cost-80.netlify.app
```

- 任何人打开 → 注册/登录 → 选城市（80 个，可搜索）→ 查酒店/门票/城际车费 → 一键算总价
- 管理员：`admin` / `123456`（登录后进数据管理，改完用户端刷新立刻生效）
- **你的电脑关机也不影响**，这是云上的站点

## 它是怎么跑的

| 层 | 在哪 |
| --- | --- |
| 页面（HTML/CSS/JS） | Netlify 全球 CDN（静态托管，快） |
| 接口（/api/*） | Netlify Functions（Node 20，Express 原样跑在函数里） |
| 数据库 | TiDB Cloud Serverless（AWS 新加坡，MySQL 兼容，免费档 5GiB） |
| 代码 | GitHub 公开仓库 `xcm0704/travel-cost-site`，main 分支 |

## 以后怎么改（最常用两件事）

**1. 改价格/加数据** —— 不用改代码：`admin` 登录 → 数据管理 → 改完保存，用户端刷新即见。

**2. 改代码/改页面** —— 改完提交 → GitHub Desktop 点 `Push origin` → Netlify 自动构建（2-4 分钟）→ 网址不变，自动生效。

## 现在这台电脑上还能干什么

- 本地开发：`npm run dev:server` + `npm run dev:web`（改代码即时看效果，用本地 MySQL，不碰云库）
- 本地库在 `D:\mysql-data`（端口 3306，root 空密码，库 `travel_cost`）；云库连接信息在 `server/.env.cloud`
- 万一哪天想临时给别人看、又不想等 Netlify：`一键启动-公网网址.cmd` 还是能起一个临时隧道网址（会变、要电脑开着）

## 已知的坑

1. Netlify 函数冷启动 1-2 秒（闲置一会儿后第一次打开会慢一下），属正常。
2. 酒店/景点价格是**参考价**，点「去携程看实时价」看当天真实价；车费是按里程测算的参考价。
3. `server/.env.cloud` 里有云库密码，别提交、别外发。
4. 免费额度：TiDB Serverless 5GiB 存储 + 5000 万请求单元/月；Netlify 免费档 100GB 流量/月。当前用量远低于上限。

## 历史（为啥最后落在 Netlify）

先用 Render，Blueprint 和普通 Web Service 都被「新账号必须绑卡验证」挡住，用户不绑卡 → 改 Netlify（不绑卡、支持 Node 函数、静态走 CDN）。
后端为此做了一层 serverless 适配：Express 拆成 `server/src/app.js`（只组装）+ `server/src/index.js`（本地 listen）、`netlify/functions/api.js`（serverless-http 包装 + `/api` 前缀剥离）、根目录 `netlify.toml`（构建/发布/函数/重定向）。
