## 它靠什么撑着（必须知道的三条）

1. **你这台电脑要开着**，网站服务和隧道进程都在跑；关机、睡眠、断网就失效。
2. **重启一次网址就换一个**（免费隧道给的是随机子域名）。换网址后重新发一遍即可，数据一条不丢。
3. 走的是免费公共隧道，速度取决于你的上行带宽；并发人多会慢。

## 怎么重启、怎么拿到新网址

双击项目根目录里的 **`一键启动-公网网址.cmd`**：
它会先检查前端打包 → 起网站服务（3000）→ 生成公网网址，窗口里 `https://` 开头那行就是发给好友的地址。

只想在自己电脑上看：`npm start` 后打开 http://localhost:3000 即可（不需要隧道）。

## 想彻底不依赖你的电脑（永久网址）

那就要真正的云服务器，方案已备好：`docs/部署上线.md` 的 B 节（Render 免费 Web 服务 + TiDB Cloud 免费数据库）。
需要你本人注册 GitHub / TiDB / Render 三个账号，跟着文档点，约 1 小时，之后网址永远在线、你电脑关机也不影响。
