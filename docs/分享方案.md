# 分享方案 · 把网址发给别人的所有办法

> 正式网址：**https://travel-cost-80.netlify.app**
> 素材文件：`分享\网址二维码.png`（900×900 纯二维码）、`分享\分享海报.png`（1080×1440 带标题的整张图）

## 一、五种发法（按场景挑）

| # | 方法 | 怎么用 | 适合 |
| --- | --- | --- | --- |
| 1 | **直接发链接** | 复制 `https://travel-cost-80.netlify.app` 粘进微信/QQ/短信/邮件 | 一对一、群里、短信 |
| 2 | **发二维码图片** | 发 `分享\网址二维码.png`；对方在微信里**长按图片 → 识别二维码** | 微信里最稳，不受长链接影响 |
| 3 | **发分享海报** | 发 `分享\分享海报.png`（含标题+二维码+说明） | 朋友圈、客户群、名片、宣传 |
| 4 | **站内分享按钮** | 网站右上角「分享」→ 弹出二维码 + 复制链接 | 对方已经打开网站时 |
| 5 | **扫码当面用** | 手机「扫一扫」/相机扫海报上的二维码 | 面对面、贴纸、展会 |

## 二、微信里的三个实用细节

1. **好友聊天发链接**：粘链接 → 发送，微信会自动显示网页标题「行价 · 旅游费用查询」。
2. **朋友圈发**：建议发**海报图**（朋友圈对链接不友好，容易被折叠；发图 + 一句话更醒目）。
3. **对方打开后想变成"桌面 App"**：
   - iPhone：Safari 打开 → 底部「分享」→「添加到主屏幕」
   - 安卓：微信里点右上角「···」→「在浏览器打开」→ 浏览器菜单「添加到主屏幕」

## 三、可直接复制的文案（三版）

**① 一句话版（群里/短信）**
> 出门前先算清这趟要花多少：酒店、门票、机票高铁一次算完 → https://travel-cost-80.netlify.app

**② 带说明版（发给客户/朋友）**
> 给你个查旅费的小工具：选好城市和出发地，勾酒店、景点、车票，一键算出这趟总价，还能点「去携程看实时价」对一下当天价格。微信里直接打开就行，注册只要用户名和密码：https://travel-cost-80.netlify.app

**③ 朋友圈版（配海报图）**
> 做了个小工具「行价」：80 个旅游城市的酒店、门票、城际车费都能查，选好东西一键算总价。出门前先算清楚，别到了地方才发现超预算 😄 扫码或点链接都能用 → https://travel-cost-80.netlify.app

## 四、想更专业一点（可选，都是免费的）

1. **换一个自己的域名**（例如 `xingjia.cn`，几十块一年）：Netlify → Domain management → Add a domain → 按提示改 DNS，网址就变成你自己的品牌名，二维码要重新生成一次。
2. **打印二维码贴纸**：二维码 PNG 拿去打印店做 5cm 小贴纸，贴店门口/名片/宣传页。
3. **公众号菜单**（如果你有）：后台「自定义菜单」→ 跳转网页 → 填这个网址，粉丝点菜单直接进。

## 五、注意

- 网址是 HTTPS，微信/浏览器都不会提示不安全。
- 接口冷启动约 1-2 秒：闲置一阵后**第一个**打开的人会稍慢一下，之后很快；这不是坏了。
- 价格是**参考价**（页面已标注），点「去携程看实时价」可核对当天真实价。
- 管理端账号 `admin/123456` 只给你自己用，**别写进分享文案/海报**。
