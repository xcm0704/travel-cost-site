# 数据扩容方案 V1.0（80+ 城市）

> 目标：覆盖 80 个旅游城市，每城 10-12 家酒店 + 5-8 个景点；城际车费按里程测算生成。
> 价格口径：**参考价**，页面标注"以实际为准"，管理端可随时改；每条记录带平台外链（去携程/美团看实时价）。

## 一、数据契约（三个数据文件 + 一个生成器）

数据文件放 `server/db/data/`，由三路并行产出，互不写同一个文件：

- `cities-part-A.json`（城市 1-27）
- `cities-part-B.json`（城市 28-54）
- `cities-part-C.json`（城市 55-80）

### 1.2 硬性规则（不满足会被打回）

1. **酒店必须是真实存在的酒店**（连锁品牌门店或当地知名酒店），不许编造。查不到时换一家查得到的。
2. 每城 **10-12 家**，价格要分布开：经济 120-300 至少 3 家、舒适 300-700 至少 4 家、高档 700-2000 至少 2 家。
3. 每城 **5-8 个景点**，门票用整数元；免费景点写 0，并在 note 里写"免费开放"。
4. `source` 必填：写清你怎么查到的（查询词 + 看到的价位），这是价格可信度的凭据。
5. `lat`/`lon` 给到小数点后 2-3 位（用于测算车费），城市中心即可。
6. `pinyin` 全小写无空格（拼外链用）。
7. 价格是**参考价**，允许是区间中点，但不许离真实价位太远（经济型 120-300、五星 600+ 这种常识要守住）。

### 1.3 城际车费（不手写，按里程测算生成）

`server/scripts/gen-transports.js` 读所有城市坐标，按以下规则生成并 upsert：

- 直线距离 `d`（公里，haversine）
- 高铁（d ≤ 1500 才生成）：`duration = max(40, round(d/250*60))`，`price = max(60, round(d*0.45))`
- 飞机（d ≥ 600 才生成）：`duration = round(d/700*60)+60`，`price = max(400, round(d*0.62))`
- 自驾（d ≤ 2000 才生成）：`duration = round(d/85*60)`，`price = round(d*1.1)`
- 覆盖范围：**8 个枢纽**（北京、上海、广州、深圳、成都、西安、杭州、武汉）× 全部城市，双向；再加 12 个热门城市两两互连
- `note` 统一写「参考测算价（按里程估算），实际以购票平台为准」
- 手工策展的 42 条真实线路**保留优先**：生成后在 seed 里用真实价覆盖（ON DUPLICATE KEY UPDATE）

## 二、表结构改动

```sql
ALTER TABLE destinations ADD COLUMN ref_url VARCHAR(255) DEFAULT '';  -- 携程城市页
ALTER TABLE hotels      ADD COLUMN ref_url VARCHAR(255) DEFAULT '';  -- 携程城市酒店列表
ALTER TABLE attractions ADD COLUMN ref_url VARCHAR(255) DEFAULT '';  -- 携程城市景点页
```

外链规则（后端按城市生成，不逐条手写）：
- 酒店：`https://hotels.ctrip.com/hotel/{pinyin}`
- 景点：`https://you.ctrip.com/sight/{pinyin}.html`
- 目的地：`https://you.ctrip.com/place/{pinyin}.html`

## 三、前端要做的三件事

1. 酒店/景点卡片加「去携程看实时价 ↗」（新窗口打开 `refUrl`，没有就不显示）
2. 分享：底部/导航加「分享」按钮 → 弹二维码（当前网址）+「复制链接」
3. `index.html` 加分享卡片 meta（title / description / og:title / og:description），微信里贴链接有标题和说明

## 四、验收标准

1. `npm run db:setup` 一把灌完，幂等；导入后 `destinations ≥ 80`、`hotels ≥ 800`、`attractions ≥ 400`、`transports ≥ 1200`
2. 抽样 10 家酒店、10 个景点在携程能搜到同名（人工抽查）
3. 用户端：城市列表能滚动选到 80 个；选任意城市都有 ≥10 家酒店；任意两个城市（含枢纽）都能算出总价
4. 页面明确显示「参考价，以实际为准」与平台外链
5. 全部有真实命令输出/接口返回作证
