```
https://o3fvia-ip-36-161-152-28.tunnelmole.net
```

已实测：公网打开自动进登录页 → 注册 → 选城市（80 城）→ 查酒店/门票/车费 → 算总价，全链路通。管理员 `admin` / `123456` 同样可用。

## 三条铁律（必须知道）

1. **这台电脑要开着**，网站服务和隧道进程都得在跑；关机、睡眠、断网就失效。
2. **每次重启会换一个新网址**（免费隧道给的是随机子域名），数据一条不丢。换网址后重新发一遍即可。
3. 速度取决于你的上行带宽，人多会慢。

## 怎么重启、怎么拿新网址

双击项目根目录的 **`一键启动-公网网址.cmd`**：
先检查前端打包 → 起网站服务（3000）→ 起隧道（约 15 秒）→ 窗口里 `https://` 开头那行就是发给好友的地址。

只想自己电脑上看：`npm start` 后打开 http://localhost:3000（不需要隧道）。
